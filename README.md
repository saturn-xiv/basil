# BASIL - A log aggregation and monitoring solution

## Usage

- Building

```bash
sudo apt install snmp libboost-all-dev libsnmp-dev libcurlpp-dev
```

- Deployment

```bash
sudo apt install snmpd libboost-log1.83.0 libboost-program-options1.83.0 libboost-json1.83.0 libsnmp40t64 libcurlpp0t64
sudo timedatectl set-timezone UTC
```
